# 错误码与反馈

发生硬错误后停止当前成功交付。反馈必须包括：失败原因、已知可用选项、用户下一步动作。可在 errors[] 中包含 code、file、page、target、available、matched、field、message。

| 代码 | 条件 | 反馈要点 |
|---|---|---|
| E1001 | 组件目标功率无匹配 | 报目标 Wp、规格书全部可用档位、请核对收资功率或补正确规格书 |
| E1002 | 组件功率对应多个型号 | 列出候选型号，请用户选择 |
| E2001 | 逆变器目标功率无匹配 | 报目标 kW、全部可用档位、请核对或补文件 |
| E2002 | 逆变器功率对应多个型号 | 列出候选型号，请用户选择 |
| E1003 | 无法定位/可靠读取规格书参数表或必需字段 | 指明文件、页码、未确认字段；建议提供可检索文字版或更清晰扫描件 |
| E1004 | schema_version 不符合 pv-collect-v1.x | 报实际版本及支持范围 |
| E3001 | L0/L1/L2/L3 均无法识别组件数量 | 列出已尝试链路；请确认图纸或提供人工数量 |
| E3002 | 标注计数与识别计数不一致 | 列出两个数值，请用户确认；当已按标注规则选值时仍记录冲突 |
| E4001 | 排布图格式不支持 | 支持 PDF/DXF，请提供其中一种 |

警告不阻断：W1001 默认衰减已采用（字段 confidence=assumed）；W3002 图面标注与自动计数不一致，记录两值并按 L0 标注值输出。若需求同时列出 E3002 硬错误与 W3002 警告，采用更明确的条件：有可信 L0 标注则输出标注值并记 W3002；只有需要用户决定且无法按此规则定值时才以 E3002 暂停。不得静默丢弃不一致。

运行期输入错误（如纯静态 HTML 没有浏览器 localStorage 数据）使用 INPUT_ERROR 通用输入错误，不得冒用 E1004；E1004 仅用于 schema_version 缺失或不兼容。

W1001 仅在规格书未给首年/逐年衰减率、也未提供可确认的保留率换算时使用：P 型 2%/0.55%，N 型 1%/0.4%；字段标记 `source=default`、`confidence=assumed`。

其他运行期错误码：`INPUT_ERROR` 表示缺失/无法解码的输入，`SCHEMA_VALIDATION` 表示合并结果校验失败。二者均停止本次成功交付并反馈修正动作；不冒用 E1003（规格书参数表无法可靠读取）。`W0001` 表示某输入分支缺失、该分支未执行，其他独立分支可继续。
